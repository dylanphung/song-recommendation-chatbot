# Data

| File | Contents | Included? |
|---|---|---|
| `small-talk.csv` | Small-talk questions and answers | Yes |
| `spotify-songs.csv` | The **Spotify Tracks Dataset** by Maharshi Pandya: 114,000 tracks across 114 genres (BSD licence). Download it from [Hugging Face](https://huggingface.co/datasets/maharshipandya/spotify-tracks-dataset) or Kaggle and save it here as `spotify-songs.csv`. **Required.** | No (too large) |
| `COMP3074-CW1-Dataset.csv` | 1,473 question-answer pairs from the WikiQA corpus, provided with the university module. **Optional:** without it, the bot skips general knowledge questions. | No |
